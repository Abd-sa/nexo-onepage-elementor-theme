## تست روی Local

```bash
git pull origin main
```

1. پیشخوان → **تنظیمات NEXO**
2. کلیک **نصب دمو NEXO** و Confirm
3. بررسی:
   - منوی ظاهر → منوها → «منوی اصلی NEXO»
   - نمونه کارها: چند پروژه فارسی
   - نظرات مشتریان: ۳ نظر
   - فرانت: منو و محتوا
4. Elementor را باز کنید و سکشن‌ها را ببینید
5. لوگو: ظاهر → سفارشی‌سازی → هویت سایت
