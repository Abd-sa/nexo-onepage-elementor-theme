- `.gitignore`، `.DS_Store`، `node_modules`
- فایل‌های dev مثل `docs/PHASE-*.md` (اختیاری؛ می‌توانید حذف کنید از ZIP مشتری)

### ساخت ZIP تمیز (ویندوز / PowerShell مثال)

```powershell
cd D:\path\to\parent
Compress-Archive -Path .\nexo-onepage-elementor-theme\* -DestinationPath .\nexo-onepage-elementor-theme-1.6.0.zip
```

روی لینوکس/مک:

```bash
cd /path/to/themes
zip -r nexo-onepage-elementor-theme-1.6.0.zip nexo-onepage-elementor-theme \
  -x "*/.git/*" "*/.git" "*/node_modules/*"
```
