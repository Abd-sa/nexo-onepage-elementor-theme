# راهنمای کاربری قالب NEXO OnePage

نسخه مستندات: هم‌تراز با قالب **1.6.0**

---

## ۱. معرفی

NEXO یک قالب وان‌پیج وردپرس برای رزومه، پورتفولیو و معرفی شخصی است که با **Elementor** (نسخه رایگان و Pro) کار می‌کند.

ویژگی‌های اصلی:

- پنل **تنظیمات NEXO** (رنگ، فونت، Hero، شبکه‌های اجتماعی)
- CPT **نمونه کارها** و **نظرات مشتریان**
- ویجت‌های اختصاصی Elementor
- RTL و فونت Vazirmatn
- نصب دمو با یک کلیک
- فرم تماس داخلی (بدون افزونه اجباری)

---

## ۲. نیازمندی‌ها

| مورد | حداقل |
|------|--------|
| وردپرس | 6.0+ |
| PHP | 7.4+ (پیشنهاد 8.0 یا 8.1) |
| Elementor | پیشنهادی (رایگان کافی است) |
| حافظه PHP | 128MB+ |

افزونه‌های پیشنهادی (اختیاری):

- Elementor Pro (اختیاری؛ برای Dynamic Tags پیشرفته)
- Yoast / Rank Math برای سئو

---

## ۳. نصب

1. فایل ZIP قالب را از راست‌چین دانلود کنید.
2. در پیشخوان: **ظاهر → پوسته‌ها → افزودن → بارگذاری پوسته**
3. ZIP را انتخاب و **هم‌اکنون نصب** را بزنید.
4. **فعال‌سازی** کنید.
5. (پیشنهادی) افزونه **Elementor** را نصب و فعال کنید.

پس از فعال‌سازی، صفحه «خانه» ساخته می‌شود و به‌عنوان صفحه اصلی تنظیم می‌گردد.

> **توجه:** قالب زبان سایت را عوض نمی‌کند. برای RTL از **تنظیمات → عمومی → زبان سایت = فارسی** استفاده کنید.

---

## ۴. نصب دمو با یک کلیک

1. بروید به **تنظیمات NEXO** در منوی پیشخوان.
2. دکمه **نصب دمو NEXO** را بزنید و تأیید کنید.
3. انجام می‌شود:
   - نمونه کارها و دسته‌ها
   - نظرات مشتریان
   - منوی اصلی با لینک سکشن‌ها
   - متون فارسی Hero
   - طراحی Elementor (فقط اگر صفحه خالی باشد)

اگر طراحی Elementor از قبل دارید، بازنویسی نمی‌شود مگر از دکمه **بازنشانی فقط طراحی Elementor** استفاده کنید.

---

## ۵. تنظیمات NEXO

مسیر: **پیشخوان → تنظیمات NEXO**

| بخش | کاربرد |
|------|--------|
| رنگ‌ها | Primary، Secondary، Accent، متن، پس‌زمینه |
| تایپوگرافی | فونت تیتر/متن + اندازه H1/H2/بدنه |
| Hero | بج، نام، زیرعنوان، توضیحات |
| شبکه‌های اجتماعی | لینکدین، Behance، Dribbble، اینستاگرام |
| عمومی | عرض محتوا، تعداد نمونه کار/نظر، انیمیشن، متن فوتر |
| کد سفارشی | CSS و JS اضافه |

**لوگو و فاویکون:** ظاهر → سفارشی‌سازی → هویت سایت (لینک داخل پنل تنظیمات هم هست).

---

## ۶. ویرایش با Elementor

1. **صفحات → خانه → ویرایش با Elementor**
2. یا از نوار ادمین بالای سایت: Edit with Elementor
3. ویجت‌های اختصاصی در دسته **NEXO**:
   - NEXO نمونه کارها (گرید + فیلتر)
   - NEXO نظرات مشتریان

پس از ذخیره، خروجی همان طراحی Elementor است.

---

## ۷. افزودن نمونه کار

1. **نمونه کارها → افزودن**
2. عنوان، متن، تصویر شاخص
3. دسته‌بندی (برای فیلتر)
4. متاباکس: نام مشتری + لینک پروژه
5. انتشار

صفحه تک‌نوشته و آرشیو (`/portfolio/`) به‌صورت خودکار کار می‌کنند.

---

## ۸. افزودن نظر مشتری

1. **نظرات مشتریان → افزودن**
2. نام در عنوان، متن نظر در ویرایشگر
3. تصویر آواتار = تصویر شاخص
4. نقش/شرکت و امتیاز ۱–۵
5. انتشار

---

## ۹. منو

بعد از دمو، منوی «منوی اصلی NEXO» به موقعیت **منوی اصلی** وصل است.

برای ویرایش دستی: **ظاهر → فهرست‌ها**

لینک‌های پیشنهادی:
- `#about` `#services` `#portfolio` `#testimonials` `#pricing` `#faq` `#contact`

---

## ۱۰. فرم تماس

فرم بخش تماس بدون افزونه کار می‌کند و پیام را به **ایمیل مدیر** سایت می‌فرستد.

در محیط Local ممکن است ایمیل واقعی ارسال نشود (وابسته به پیکربندی سرور).

می‌توانید فرم Elementor یا Contact Form 7 را جایگزین کنید.

---

## ۱۱. سوالات متداول فنی

**صفحه اصلی در لیست صفحات نیست؟**  
باید صفحه «خانه» باشد. اگر نیست، دوباره تم را یک‌بار غیرفعال/فعال کنید یا از نصب دمو استفاده کنید.

**Elementor خالی است؟**  
از تنظیمات NEXO → بازنشانی طراحی Elementor (با تأیید) استفاده کنید.

**RTL فعال نیست؟**  
زبان سایت را فارسی کنید یا افزونه/تنظیم RTL وردپرس را بررسی کنید.

**ویجت‌های NEXO دیده نمی‌شوند؟**  
Elementor → Tools → Regenerate CSS & Data و کش مرورگر را خالی کنید.

**بعد از آپدیت طراحی از بین رفت؟**  
نسخه ۱.۳ به بعد طراحی موجود را خودکار پاک نمی‌کند. فقط دکمه بازنشانی با تأیید این کار را می‌کند.
