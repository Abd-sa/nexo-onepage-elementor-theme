## تست نصب تمیز (روی Local)

### آماده‌سازی
1. سایت Local جدید یا دیتابیس ریست
2. وردپرس آخرین نسخه + PHP 8.0 یا 8.1
3. `git pull` داخل پوشه تم

```bash
cd wp-content/themes/nexo-onepage-elementor-theme
git pull origin main
```

### مراحل
1. فعال‌سازی تم **NEXO OnePage** بدون Elementor → نباید fatal error بدهد
2. نصب و فعال‌سازی **Elementor**
3. رفرش پیشخوان → notice نصب/ویرایش (نه خطا)
4. باز کردن فرانت سایت → صفحه نمایش داده شود (PHP sections یا Elementor)
5. **صفحات → خانه** در لیست باشد
6. **ویرایش با Elementor** باز شود
7. ذخیره یک تغییر کوچک در Elementor → بعد از رفرش باقی بماند (overwrite نشود)
8. زبان سایت را دستی فارسی کنید (تنظیمات → عمومی) → RTL فعال شود
9. دکمه «بازنشانی طراحی پیش‌فرض» → فقط بعد از Confirm کار کند
