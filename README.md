# NEXO OnePage

قالب حرفه‌ای وان‌پیج شخصی / رزومه / پورتفولیو برای وردپرس + Elementor  
آماده‌سازی برای فروش در **راست‌چین**

**نسخه فعلی:** 1.6.0  
**مخزن:** https://github.com/Abd-sa/nexo-onepage-elementor-theme

---

## ویژگی‌ها

- پنل **تنظیمات NEXO** (فارسی): رنگ، فونت، Hero، شبکه‌های اجتماعی، CSS/JS
- CPT نمونه کارها + نظرات مشتریان
- ویجت Elementor: گرید پورتفولیو (با فیلتر) و نظرات
- نصب دمو با یک کلیک
- RTL + Vazirmatn
- فرم تماس AJAX داخلی
- قالب single و archive پورتفولیو
- سازگار با Elementor Free و Pro

---

## نصب سریع

1. آپلود و فعال‌سازی تم
2. نصب Elementor
3. **تنظیمات NEXO → نصب دمو NEXO**
4. زبان سایت را در صورت نیاز فارسی کنید (RTL)
5. لوگو از ظاهر → سفارشی‌سازی
